# Portafolio profesional — Gustavo Adolfo Calume Pineda

Sitio web personal estático, adaptable a móviles, creado con HTML, CSS y JavaScript puro.

## Contenido
- `index.html`: contenido y secciones del portafolio.
- `styles.css`: tema oscuro, tipografía clara, diseño adaptable y animaciones.
- `script.js`: menú móvil, animaciones al desplazarse, barra de progreso y botón para volver arriba.

## Publicar en GitHub Pages
1. Descomprime el ZIP.
2. Crea un repositorio nuevo en GitHub.
3. Sube `index.html`, `styles.css`, `script.js` y `README.md` a la raíz del repositorio.
4. Abre **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
7. Espera a que GitHub Pages publique el sitio y abre la URL que te indique.

## Personalización antes de publicar
- Reemplaza el enlace genérico de LinkedIn en `index.html` por tu URL pública real o elimina ese botón.
- La hoja de vida no especifica hobbies personales; la sección “Intereses” está redactada como intereses profesionales relacionados con la trayectoria.
- Se omitieron correo, teléfonos, dirección, fecha/lugar de nacimiento, documento de identidad y datos de contacto de referencias.
- La cifra “20+” es una estimación basada en las fechas de trayectoria incluidas en la hoja de vida.
- La tipografía se carga desde Google Fonts; si no hay conexión, se usarán fuentes alternativas.

## Tecnologías
HTML5 · CSS3 · JavaScript vanilla. No requiere compilación ni dependencias.
